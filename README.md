Project: DFS for Protein Interaction Pathways
Language: Python 3

Requirements:
- Python 3 installed
- No external libraries required

Steps:
1. Save the program as Gxx_T9_project.py.
2. Open a terminal in the file's directory.
3. Run: python Gxx_T9_project.py
4. Choose an option from the main menu.
5. Enter protein identifiers such as P1 and P6
   when prompted for path finding.

Modules:
1. Connected Components
2. Cycle Detection
3. Path Finding

Dataset:
20 synthetic protein identifiers (P1 to P20).
